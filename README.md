# CrowShow 1.0

PDF 수업 자료를 오프라인에서 프레젠테이션처럼 활용하는 `Crow Science Lab`의 전용 플레이어입니다.

> **Gemini Notebook & AI 슬라이드를 위한 전용 프레젠테이션 플레이어**  
> PDF를 슬라이드 원본으로 사용하면서 PowerPoint 슬라이드 쇼 수준의 발표 도구, 펜 필기, 레이저 포인터, 스포트라이트, 화면 전환 효과를 제공하는 전용 로컬 플레이어입니다.

---

## 1. 프로젝트 목적 및 철학

PowerPoint 전체를 복제하지 않습니다.  
이 프로젝트는 **"PDF 원본을 100% 무손실로 유지하면서, PowerPoint 슬라이드 쇼에 필적하는 고성능 발표 환경을 제공"**하는 것을 목표로 합니다.

- **PDF 원본 불변**: 필기나 효과가 원본 PDF 파일을 변경하지 않습니다.
- **5단계 레이어 분리**:
  1. `PDF Render Layer` (Mozilla PDF.js 기반 고해상도 백그라운드 렌더링)
  2. `Slide Display Layer` (화면 종횡비 자동 맞춤, 줌/팬 처리)
  3. `Annotation Layer` (정규화된 벡터 좌표계 기반 펜/형광펜/지우개)
  4. `Presentation Effect Layer` (레이저 포인터 잔상, 스포트라이트 조명, 블랙/화이트 커튼)
  5. `Presentation Control Layer` (전체화면 슬라이드쇼, 플로팅 툴바, 발표자 모드)

## 2. 주요 핵심 기능

### A. 슬라이드 로딩 및 관리
- **PDF 파일 열기 & 드래그 앤 드롭**: 파일 탐색기 또는 브라우저 창으로 즉시 로드.
- **체험용 5-슬라이드 내장**: 별도 PDF 파일 없이도 "체험용 샘플 슬라이드" 버튼으로 즉시 테스트 가능.
- **주변 슬라이드 사전 렌더링 (Preloading)**: 현재 슬라이드 기준 $\pm 2$장을 백그라운드 오프스크린 캔버스에 미리 렌더링하여 슬라이드 넘김 시 **0ms 지연** 보장.
- **슬라이드 썸네일 탐색기**: 좌측 사이드바에 각 페이지 축소판 자동 렌더링 및 현재 슬라이드 강조 표시.

### B. PowerPoint급 슬라이드 쇼 (F5)
- **F5 / 전체화면**: 단축키 F5 또는 "슬라이드 쇼" 버튼으로 즉시 방해 요소 없는 전체화면 발표 시작.
- **플로팅 툴바 (Floating Toolbar)**: 발표 중 하단 중앙에 반투명 컨트롤 바 제공. 마우스 미조작 2.5초 후 자동 숨김(Auto-hide), 마우스 이동 시 즉시 복귀.
- **블랙/화이트 스크린 커튼**:
  - `B`: 청중의 시선을 발표자에게 모으기 위한 Black Screen 토글.
  - `W`: White Screen 토글.

### C. 강력한 펜 & 필기 도구
- **펜 (Pen)**: 매끄러운 2차 베지어 곡선(Quadratic Bezier) 보간으로 자연스러운 손글씨 느낌 구현. 다양한 팔레트 색상 및 선 굵기 조절.
- **형광펜 (Highlighter)**: `multiply` 블렌드 모드로 텍스트를 가리지 않는 반투명 형광 마킹.
- **획 단위 벡터 지우개 (Stroke-based Eraser)**: 복잡한 지우개질 없이, 스친 획(Stroke) 전체를 한 번에 지우는 스마트 히트 테스트 알고리즘.
- **무제한 실행 취소/다시 실행**: `Ctrl + Z`, `Ctrl + Y` 완벽 지원.
- **정규화 좌표계**: 슬라이드 해상도/크기/줌 비율이 바뀌어도 필기 위치가 어긋나지 않도록 $[0.0, 1.0]$ 정규화 좌표로 저장.

### D. 실시간 발표 효과
- **레이저 포인터 (Laser Pointer)**: 레드/그린 발광 링 및 부드러운 이동 잔상(Trail) 효과.
- **스포트라이트 (Spotlight)**: 화면 전체를 어둡게 처리하고 마우스 커서 주변만 원형으로 밝게 비추어 청중의 집중도 극대화.
- **슬라이드 전환 애니메이션 (Transition Engine)**:
  - 페이드(Fade), 슬라이드 좌/우/상/하(Slide Left/Right/Up/Down), 줌(Zoom), 디졸브(Dissolve).
  - 하드웨어 가속 CSS 3D 트랜스폼 기반 60fps 부드러운 전환.

### E. 발표자 모드 (Presenter Studio)
- 청중에게 나가는 **현재 슬라이드**와 **다음 슬라이드 미리보기**를 동시에 제공.
- 실시간 시계 및 **발표 경과 타이머 (Elapsed Timer)** 내장.
- 슬라이드별 발표자 메모 & 키노트 기록창 지원.

| 기능 | 단축키 |
| :--- | :--- |

| **슬라이드 쇼 종료 / 모달 닫기** | `Escape` |
| **다음 슬라이드** | `→`, `↓`, `PageDown`, `Space`, 마우스 휠 아래 |
| **이전 슬라이드** | `←`, `↑`, `PageUp`, `Backspace` |
| **첫 / 마지막 슬라이드** | `Home` / `End` |
| **슬라이드 직접 이동 (Go to)** | `Ctrl + G` |
| **블랙 스크린 토글** | `B` |
| **화이트 스크린 토글** | `W` |
| **실행 취소 / 다시 실행** | `Ctrl + Z` / `Ctrl + Y` (또는 `Ctrl + Shift + Z`) |
| **도구 선택: 일반 포인터** | `V` |
| **도구 선택: 펜** | `P` |
| **도구 선택: 형광펜** | `H` |
| **도구 선택: 지우개** | `E` |
| **도구 선택: 레이저 포인터** | `L` |
| **도구 선택: 스포트라이트** | `S` |
| **화면 확대 / 축소 / 맞춤** | `+` / `-` / `0` |
| **다음 / 이전 슬라이드** | 마우스 휠 아래 / 위 |

## 4. 빠른 실행 방법

```bash
# 1. 의존성 설치
npm install

# 2. 로컬 개발 서버 실행
npm run dev

# 3. 브라우저에서 접속 (Windows 패키징 전 개발 모드)
# http://localhost:5173
```

## 5. 프로젝트 데이터 포맷 (`.crowshow`)

PDF 원본과 분리하여 필기 스트로크, 전환 설정, 슬라이드 설정을 보관할 수 있는 JSON 기반 프로젝트 포맷(`.crowshow`)의 내보내기/가져오기를 지원합니다.
또한 브라우저 LocalStorage에 문서별로 실시간 자동 저장(Auto-save)됩니다.

PDF 원본은 IndexedDB 기반 최근 파일 보관함에 저장되므로 다시 선택하지 않고 열 수 있습니다.
초기 개발 단계의 텍스트 도구는 별도 글꼴을 포함하지 않고 운영체제 기본 글꼴을 사용합니다.

Windows 설치판의 업데이트, 보안 경고 및 PDF 기본 앱 연결 정책은
[DISTRIBUTION.md](DISTRIBUTION.md)를 따릅니다.
