# CrowShow 1.5 — PDF 발표와 필기, Notebook을 한곳에서

CrowShow는 교사·강사·발표자가 PDF 수업 자료를 열고 바로 발표·필기할 수 있는 Windows PC 앱입니다. PDF 본문을 슬라이드로 활용하고, 별도의 Notebook에 설명과 풀이를 정리할 수 있습니다. 문서 열기·필기·발표의 핵심 기능은 인터넷 없이 동작합니다.

## 주요 기능

- PDF 수업 자료를 전체화면 슬라이드쇼로 발표하고, 썸네일·전환 효과·전환음·타이머·자동 재생·발표자 메모·별도 청중 창을 활용합니다.
- 펜·형광펜·텍스트·12종 도형으로 필기하며, 선택·사각 영역·올가미·객체/영역 지우기와 실행 취소·다시 실행을 지원합니다.
- 도형의 너비·높이·크기를 개별 조절하고 자유 회전·각도 입력·반전·복사·색상 변경을 사용합니다. 텍스트의 글꼴·굵게·기울임·밑줄·외곽선을 조합합니다.
- 레이저의 빛나는 점과 잔상, 검은 화면·흰 화면 가리기로 발표 흐름을 조절합니다. 편집·발표·노트에서 같은 하단 도구를 사용합니다.
- PDF와 노트의 너비 맞춤을 100%로 표시하고, 페이지 맞춤·단계별 확대·축소·스크롤·우클릭 드래그로 문서를 이동합니다.
- Notebook에서 여러 노트와 페이지를 관리합니다. 무지·줄·모눈·점·코넬·스프링 용지, 배경색, 한/두 페이지 보기, 이미지 붙여넣기·추가, 하이퍼링크와 PDF 가져오기를 지원합니다.
- 편집 가능한 .crownotebook 독립 파일, .crowshow 프로젝트, 필기 포함 PDF 및 노트 PDF로 저장합니다. PC용 Google Drive 동기화 폴더를 지정해 노트 파일을 보관하고 불러옵니다.
- PDF 페이지를 삽입·복사·회전·삭제하고 드래그로 순서를 바꾼 뒤 저장합니다. 인쇄 미리보기에서 페이지 범위·한 면의 장수·필기 포함·용지 방향을 선택합니다.
- 한글/CJK 문자 매핑·표준 글꼴·이미지/색상 리소스를 설치본에 포함합니다. 큰 PDF는 첫 페이지와 주변 썸네일부터 처리합니다.
- Dark·Light·밝은 Pink·밝은 Blue 테마, 기능·단축키 상세 도움말을 제공합니다.

## 1.5 개선 사항

- 도형의 독립 너비·높이 조절과 자유 회전·각도 입력을 복원하고 선택 도구를 보강했습니다.
- 선택한 팔레트 색을 유지하면서 원형 테두리로 선택 상태를 표시합니다.
- 많은 필기를 쓸 때 전체 문서 복제와 동기 저장이 반복되던 구조를 개선했습니다. IndexedDB 비동기 자동 저장, 데이터 공유 실행 취소, 완료된 획 화면 캐시를 적용했습니다.
- 마지막 노트 페이지도 삭제할 수 있으며 같은 용지·색의 빈 페이지를 자동으로 만듭니다. 삭제 실행 취소를 지원합니다.
- 인쇄 옵션을 작은 왼쪽 패널로 정리했습니다.
- 네 테마와 상세 도움말을 추가하고, 테마 버튼은 한 줄로 배치했습니다.
- 시작 시 배포 경로별 업데이트를 확인합니다. GitHub판은 공식 설치 파일과 SHA-256을 검증하고, Store판은 Microsoft Store의 패키지 업데이트를 사용합니다.
- 1.3 검토 과정의 공통 직선 도구바·발표 하위 메뉴·레이저 점과 상시 잔상·Notebook 독립 저장 개선을 포함합니다.

## 설치와 업데이트

- Windows 10 2004 이상 / Windows 11, x64.
- GitHub 배포 파일: CrowShow-v1.5-Setup-x64.exe, SHA256SUMS.txt.
- Microsoft Store판은 별도 MSIX로 배포되며 Store에서 설치·업데이트합니다.
- GitHub판은 기존 앱의 업데이트 안내 또는 설치 파일 실행으로 업데이트할 수 있습니다. Windows PDF 기본 앱을 강제로 변경하지 않습니다.
- WebView2 Runtime이 필요합니다. 문서 기능은 오프라인으로 사용하지만 초기 Runtime 준비와 앱 업데이트에는 네트워크가 필요할 수 있습니다.
- GitHub 설치 파일은 미서명입니다. 공식 배포처와 SHA-256을 확인하고 Windows 및 기관 보안 정책을 따르세요. [설치 안내](https://github.com/CrowScienceLab/CrowShow/blob/v1.5.0/WINDOWS_SECURITY.md)

## 저장·호환 및 범위

- .crownotebook은 현재 JSON 기반 편집 원본입니다. PDF는 공유·인쇄용이며 현재 노트 PDF는 페이지를 이미지로 합칩니다. 압축 패키지나 새 바이너리 형식으로 변경하지 않았습니다.
- 이전 로컬 자료는 새 비동기 저장소로 이전하며 원본 문자열 백업을 보관합니다. 구버전으로 되돌아갈 때는 먼저 파일로 내보내세요.
- Google Drive는 PC용 Drive가 동기화하는 폴더 연결 방식입니다. 앱이 Google 계정에 직접 로그인하거나 서버 업로드 완료를 확인하지 않습니다.
- 필압·기울기는 입력 장치와 Windows가 제공하는 값에 따라 달라집니다. 이미지 기반 PDF에 원래 없는 세부 정보는 생성하지 않습니다.
- 3,000획·72,000점 시험 노트에서 추가 필기·파일 저장과 재실행 자동 복원을 확인했습니다. 모든 저사양 PC·태블릿·프린터 조합의 성능을 보장하지 않습니다.
- F1을 다른 프로그램이 전역 단축키로 쓰면 상단 ? 도움말 버튼을 사용하세요.
