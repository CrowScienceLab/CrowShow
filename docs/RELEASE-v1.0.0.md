# CrowShow v1.0.0

PDF 수업 자료를 오프라인에서 프레젠테이션처럼 활용하는 Crow Science Lab의 Windows 플레이어입니다.

## 주요 기능

- PDF 슬라이드, 썸네일, 전체화면 발표 및 발표자 화면
- 펜, 형광펜, 텍스트, 벡터 도형, 지우개, 실행 취소·다시 실행
- 작은 방사형 그라데이션 레이저와 스포트라이트
- 슬라이드 전환 효과, 발표자 메모, 자동 재생
- `.crowshow` 프로젝트와 필기 포함 PDF 내보내기
- 실행 시 GitHub 정식 릴리스 확인
- 설치 파일 SHA-256 검증 후 사용자 승인형 업데이트
- Windows PDF 열기 가능 앱 등록 및 사용자 선택형 기본 앱 안내
