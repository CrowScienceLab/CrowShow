# CrowShow 1.0c 아이콘 및 텍스트 편집 개선 보고서

## 변경 내용

### Windows 애플리케이션 아이콘

- 기존 앱 내부의 사실적인 노란부리까마귀 이미지를 시각 기준으로 사용했다.
- 흰색 PDF 문서 형태, 빨간 접힌 모서리, 파란 재생 버튼을 결합해 PDF 플레이어 용도를 표현했다.
- Tauri 아이콘 생성 도구로 Windows ICO와 크기별 PNG를 포함한 플랫폼 아이콘 세트를 다시 생성했다.
- 고해상도 제작 원본: `docs/assets/crowshow-player-icon-source.png`
- 앱 파비콘용 최적화 자산: `public/crowshow-player-icon.png`

### 텍스트 편집창

- 편집창 폭 460px은 유지했다.
- 입력 영역 최소 높이를 132px에서 66px로 줄이고 기본 행 수를 5행에서 2행으로 변경했다.
- 입력 중에는 시스템 기본 글꼴, 일반 굵기, 단색 글자만 표시한다.
- 입력 완료 후 캔버스 렌더링에서만 대비 외곽선과 그림자를 적용한다.
- 축소된 창이 슬라이드 아래쪽을 벗어나지 않도록 배치 한계도 조정했다.

## 이미지 생성 기록

- 방식: OpenAI 기본 이미지 생성 도구, 기존 까마귀 이미지 참조 편집
- 최종 프롬프트 요약: 사실적인 노란부리까마귀를 유지하면서 어두운 남색의 둥근 사각형 타일, 흰색 문서, 빨간 접힌 모서리, 파란 원형 재생 버튼을 조합하고 32px에서도 읽히는 전문 Windows 앱 아이콘으로 구성. 글자·워터마크·유아적 캐릭터 표현은 제외.
