# CrowShow 2.0 검증 결과

- 다단 HWP에서 빠졌던 그림과 선택지를 수정했습니다. 두 쪽에서 그림, 선택지, 질문과 보기 표 배치를 회귀 검사했습니다.
- GitHub EXE와 Microsoft Store MSIX에 들어간 rhwp 수정본과 MIT 라이선스를 확인했습니다. 각 패키지에서 추출한 CrowShow로 원본 HWP를 열고 저장한 PDF가 그림 누락을 수정한 검증본과 바이트 단위로 일치했습니다.
- 두 번째 쪽 마지막 선택지 줄은 본문 영역을 약 7.7px 벗어나지만 페이지 안에 표시됩니다. 한컴 PDF와 글꼴, 줄 간격, 여백에 차이가 남을 수 있습니다.
- Windows 설치 및 Microsoft Store 인증은 로컬 검증에 포함되지 않았습니다.
