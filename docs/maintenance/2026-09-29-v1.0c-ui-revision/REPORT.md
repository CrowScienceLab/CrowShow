# CrowShow 1.0c UI 개편 보고서

## 범위

- Windows Tauri/WebView2 앱의 시작 화면, 상·하단 메뉴, 환경설정, 전환음 및 브랜드 이미지 개편
- 기존 1.0 작업 내역과 Git 이력은 그대로 보존
- GitHub 업로드 및 릴리스 변경은 수행하지 않음

## 주요 변경

1. 시작 화면은 실제 플레이어 형태를 배경으로 유지하고 중앙에 작은 PDF 열기 패널만 표시한다.
2. 샘플 슬라이드 버튼을 제거하고 PDF 선택 및 드래그 앤 드롭에 집중한다.
3. `dragDropEnabled: false`를 적용해 Tauri가 HTML 드롭 이벤트를 가로채지 않도록 했다.
4. 상단에는 브랜드, 열기, 슬라이드쇼, 발표자, 전환, 소리, 실행취소/다시실행, 삭제, 저장, 설정만 둔다.
5. 하단에는 슬라이드 번호, 파일명, 타이머, 도구, 확대/축소, 전체화면을 둔다.
6. 중간 메뉴 바는 제거했다.
7. 전환음은 없음, 부드러운 넘김, 종이 넘김, 짧은 클릭, 차임 중 선택한다.
8. 환경설정은 넓은 2열 카드로 구성하고 중복된 레이저 색상 및 잔상 설정을 제거했다.
9. 사실적인 노란부리까마귀 투명 PNG를 앱 UI와 패키지 아이콘 원본으로 사용한다.
