# CrowShow 1.2 PDF 크기·화질·스크롤 검토

작업일: 2026-10-02. PC 프로젝트: `D:\App coding\CrowShow`.

## 원인과 수정

첨부 Entropy_Masterclass.pdf는 18,463,623바이트·13페이지입니다. 첫 페이지 크기는 1376×768포인트,
포함된 이미지도 1376×768픽셀이며 추출할 텍스트는 없는 이미지형 PDF입니다.
기존 100%는 PDF의 실제 화면 배율이 아니라 현재 화면에 맞춘 크기였습니다.
FHD 검토 환경에서는 1664×929 CSS 픽셀로 표시되면서 100%라고 표기했습니다.

PDF 72pt를 CSS 96px로 환산하여 표준 100%를 1835×1024 CSS 픽셀로 수정했습니다.
페이지·너비 맞춤과 사용자 배율을 분리하고, 맞춤에서도 실제 배율을 표시합니다.
확대 문서는 가로·세로 스크롤바, 휠, Shift+휠, Shift/가운데 버튼 드래그로 이동합니다.
Ctrl+휠은 마우스 위치, 확대 버튼은 현재 viewport 중심의 문서 위치를 유지합니다.
PDF·필기·효과 레이어는 같은 크기의 프레임 안에서 함께 스크롤됩니다.

화면 렌더링은 보통 크기에서 최소 2배 해상도로 다시 그립니다. 캔버스의 픽셀 수는 약 16MP,
변 길이는 16384px를 기준으로 제한하며 큰 배율에서는 렌더링 밀도를 낮춥니다.
PDF 이미지 캐시는 96MiB·16항목 이내로 관리합니다. 이 수치는 앱 전체 메모리의 상한은 아닙니다.
이미지형 원본의 세부 정보와 실제 모니터의 물리적 크기까지 보장하는 변경은 아닙니다.
