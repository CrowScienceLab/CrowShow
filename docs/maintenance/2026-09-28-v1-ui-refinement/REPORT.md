# CrowShow 1.0 UI 개선 및 검증 보고서

- 작업일: 2026-09-28
- 대상: `D:\App coding\CrowShow`
- 버전: `1.0.0`

## 적용 사항

1. 텍스트 입력 편집창을 확대하고 밝은 배경으로 변경했다.
2. 편집 중인 글자와 슬라이드에 확정된 글자 모두 글자색 명도에 따라 반대 명도의 외곽선/그림자를 적용했다.
3. 슬라이드 배경의 좌·우 클릭 페이지 이동을 제거했다.
4. 마우스 휠 아래/위로 다음/이전 슬라이드가 이동하도록 했다.
5. 레이저 포인터를 단단한 원형에서 중심광과 넓은 번짐이 있는 방사형 그라데이션으로 변경했다.
6. 손가락 도형을 Google Material Icons의 `touch_app` 벡터로 교체했다.
7. 패키지 버전을 `1.0.0`으로 통일했다.
8. 미사용 기본 템플릿 자산을 `D:\App coding\_archive\CrowShow-unused-2026-09-28`로 이동했다.

## 검증 결과

- `npm.cmd run build`: 통과
- `npm.cmd run lint`: 통과
- 브라우저 실화면: 샘플 PDF 열기 통과
- 텍스트 편집창: 확대 및 밝은 배경 표시 확인
- 마우스 휠 아래: 1 → 2 슬라이드 이동 확인
- 마우스 휠 위: 2 → 1 슬라이드 이동 확인
- 선택 모드의 슬라이드 배경 클릭: 페이지가 유지됨을 확인
- 텍스트 완료 후 선택 도구 자동 전환 및 개별 수정·삭제 메뉴 표시 확인
- 텍스트 문장 영역 전체를 객체 선택 영역으로 판정하도록 오류 수정
- 레이저 포인터를 반지름 6px의 중심-외곽 방사형 그라데이션으로 축소
