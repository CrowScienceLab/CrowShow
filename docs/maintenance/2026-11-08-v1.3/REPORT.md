## 데이터와 호환성

- PDF 편집은 메모리의 작업 사본에 적용한다. 원본 디스크 파일을 자동 덮어쓰지 않는다.
- 페이지 편집 시 필기·발표 메모·전환도 함께 재매핑한다. 회전 시 필기 좌표와 텍스트 방향·굵기 기준도 변환한다.
- `편집한 PDF 저장`은 필기 제외 PDF 본문을 보존한다. `필기 포함 PDF`는 원본 PDF 요소를 유지하면서 투명 필기 이미지 레이어를 추가한다. 기존 전체 페이지 래스터화 방식을 교체했다.
- 1.3 프로젝트에는 PDF 본문(Base64), 필기, 발표 메모/설정, 노트를 함께 저장한다. 이전 프로젝트도 해당 PDF를 먼저 연 상태에서 가져올 수 있다. 외부 프로젝트의 구조를 검사한다.
- 필기/선택 변형은 한 번의 포인터 동작으로 실행 취소한다. 전체 필기 지우기도 복원할 수 있다. 필기 이력은 최대 80개, PDF 페이지 편집 이력은 최대 5개/256MiB 범위다.
- 드래그 중에는 로컬 저장과 전체 노트 직렬화를 반복하지 않고 동작 완료 시 저장한다. 화면 렌더 알림은 계속 제공한다.
- 노트는 문서별 별도 AnnotationStore를 사용해 PDF 본문 필기와 섞이지 않는다. 로컬 저장소 한계가 있어 오류 시 노트에 경고하고 프로젝트 백업을 안내한다.

## 검증

- TypeScript/Vite 빌드, oxlint, 기존 `scripts/regression.cjs` 통과.
- `scripts/v13-data.cjs`: 모든 배율 단계의 왕복, 실제 PDF 페이지 이동·복제·삭제·삽입·회전, 필기 재매핑, 실행 취소 트랜잭션, 잘못된 범위·프로젝트 거부.
- `scripts/v13-ui.cjs`: 실제 로컬 Edge UI에서 필기, 한글 서식, 우클릭 팬, PDF 페이지 편집/복원, 노트 지속성, N-up, 원형 메뉴 이동/회전, 영역 지우개/복원, 올가미 복사/붙여넣기, 회전한 필기 포함 PDF 저장·재열기와 빨간 필기 위치 비교, PDF 포함 프로젝트 왕복, 800×600 화면 확인.
- Rust 업데이트 버전/체크섬 단위 검사 통과. 네이티브 검토 실행본에서 예제 PDF 첫 화면과 실제 WebView2 인쇄 대화상자를 확인했다. 실제 프린터 출력은 실행하지 않았다.
- 이미지: `01-editor.png`, `02-notebook.png`, `03-print.png`, `04-radial.png`, `05-small-window.png`, `06-native-print.jpg`.
- 초기 배율 재현은 `100 → 축소 = 85%`로 실패했고 수정 후 `90%`가 됐다. 빠른 교차 클릭에서 한 차례 `110%` 잔류를 추가 재현하여 동기 배율 참조로 해결했다.

## 검토 시 확인할 사항

- 실제 수업 PDF와 펜 장치의 필기감·팜리젝션, 프린터의 실제 출력 및 여백, 대용량 자료의 인쇄 준비 시간을 확인할 것.
- 원형 메뉴는 280px 크기이며 추가 기능은 필요할 때 펼친다. 현재 회전 핸들의 감도와 위치는 사용자 검토 대상이다.
- CollaNote/Notability의 모든 기능과 동등하다고 주장하지 않는다. 음성·영상·AI 변환·공동 편집·Drive OAuth는 구현 범위에서 제외했다.
- 노트 PDF 및 인쇄는 래스터화한 필기/화면을 사용한다. PDF 본문 저장은 벡터 요소를 보존한다.
- 1.3 검토판은 `lab.crowscience.crowshow.review`를 사용하여 기존 앱 저장소와 분리한다. PDF 기본 연결을 등록하지 않는다. 정식 배포 전 기본/Store 식별자로 별도 최종 패키징 필요.
