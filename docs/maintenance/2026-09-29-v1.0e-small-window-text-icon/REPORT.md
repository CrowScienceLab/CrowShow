# CrowShow 1.0e 작업 및 검증 보고서

작업일: 2026-09-29  
개발자: Crow Science Lab

## 적용 내용

- Windows 창 최소 크기를 1140×680에서 760×520으로 축소했습니다.
- 900px 이하 창에서는 상단 명령 버튼을 아이콘 중심으로 줄이고, 하단 상태·도구 영역을 압축 배치하도록 반응형 규칙을 추가했습니다.
- 텍스트 입력창 안내 문구를 `텍스트 입력 (Enter 완료 · Shift+Enter 줄바꿈)`으로 줄이고 입력 글자 크기를 13px로 고정했습니다.
- 선택된 텍스트의 수정·삭제 버튼을 객체 위쪽에 배치하되 공간이 부족하면 객체 아래쪽으로 이동하도록 수정했습니다.
- PDF 슬라이드에 완료된 텍스트를 표시할 때 외곽선과 그림자를 사용하지 않고 원래 글자색만 렌더링하도록 변경했습니다.
- 노란부리까마귀·PDF 문서·재생 표시가 결합된 아이콘을 Tauri 실행 파일과 NSIS 설치 프로그램에 다시 포함했습니다.
- 사용자 표시 버전은 1.0e, 패키지 내부 SemVer는 1.0.4로 설정했습니다.

- `npm run build`: 통과
- `npm run lint`: 통과
- `cargo fmt --check`: 통과
- `cargo check --offline`: 통과
- 760×520 브라우저 화면에서 시작 화면과 플레이어의 상·하단 메뉴가 창 안에 배치되는 것을 확인했습니다.
- 완전 재빌드 후 `crowshow.exe`에서 Windows 연결 아이콘을 추출해 새 노란부리까마귀·PDF·재생 아이콘 적용을 확인했습니다.
- NSIS 설치 파일 생성: 통과

## 바탕화면 바로가기 전용 아이콘 보완

- 앱 실행 파일과 창 내부 아이콘은 변경하지 않았습니다.
- 사용자가 제공한 노란부리까마귀·PDF·재생 이미지를 Windows 다중 해상도 `.ico`로 변환했습니다.
- 전용 아이콘을 설치 리소스에 포함하고, NSIS가 바탕화면 바로가기를 만들었을 때만 해당 아이콘을 참조하도록 후처리했습니다.
- 생성된 `.ico`를 256px로 다시 렌더링해 이미지 구도와 선명도를 확인했습니다.
- 변경된 설치 프로그램을 같은 1.0e 배포 파일로 다시 패키징하고 SHA-256을 갱신했습니다.

## 참고

Windows 탐색기가 기존 바로가기 아이콘을 캐시한 경우 새 설치 후에도 잠시 이전 아이콘이 보일 수 있습니다. 새 실행 파일 자체에는 새 아이콘이 포함되어 있습니다.
