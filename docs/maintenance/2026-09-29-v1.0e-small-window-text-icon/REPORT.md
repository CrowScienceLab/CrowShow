# CrowShow 1.0e 작업 및 검증 보고서

작업일: 2026-09-29  
개발자: Crow Science Lab

## 적용 내용

- Windows 창 최소 크기를 1140×680에서 760×520으로 축소했습니다.
- 900px 이하 창에서는 상단 명령 버튼을 아이콘 중심으로 줄이고, 하단 상태·도구 영역을 압축 배치하도록 반응형 규칙을 추가했습니다.
- 텍스트 입력창 안내 문구를 `텍스트 입력 (Enter 완료 · Shift+Enter 줄바꿈)`으로 줄이고 입력 글자 크기를 13px로 고정했습니다.
- 선택된 텍스트의 수정·삭제 버튼을 객체 위쪽에 배치하되 공간이 부족하면 객체 아래쪽으로 이동하도록 수정했습니다.
- PDF 슬라이드에 완료된 텍스트를 표시할 때 외곽선과 그림자를 사용하지 않고 원래 글자색만 렌더링하도록 변경했습니다.
- 노란부리까마귀·PDF 문서·재생 표시가 결합된 아이콘을 Tauri 실행 파일과 NSIS 설치 프로그램에 다시 포함했습니다.
- 사용자 표시 버전은 1.0e, 패키지 내부 SemVer는 1.0.4로 설정했습니다.
