# CrowShow 1.0f 검토 및 배포 보고서

작업일: 2026-09-29

## 주요 수정

1. PDF 캐시를 문서 인스턴스·페이지·배율별로 분리했습니다. 서로 다른 문서의 화면이 섞이지 않습니다.
2. 첫 PDF를 연 직후 화면 크기 감지가 연결되며, 문서 변경 시 썸네일을 다시 그립니다.
3. PDF 배경과 필기·효과 레이어의 크기 계산을 일치시켰습니다.
4. 새 PDF 해석에 실패하면 이전 PDF를 유지합니다. 이전 문서와 실패한 작업의 PDF.js 워커를 해제하며, 늦게 완료된 과거 요청이 최신 문서를 덮어쓰지 않게 했습니다.
5. PDF 교체 시 자동 재생 및 검은색·흰색 가리기를 초기화합니다. 같은 파일 재선택과 파일 읽기 오류 안내, 메모·전환 설정 저장 실패 처리를 보완했습니다.
6. 사용되지 않는 체험 PDF 생성 코드를 아카이브로 이동하고, 오래된 개발·기능 문서 설명을 현행화했습니다.
7. 첨부 PNG를 docs/assets/desktop-shortcut-source.png에 보관하고 Tauri CLI로 ICO 변환했습니다. 기존 바로가기 전용 설치 후크와 리소스 매핑을 사용합니다.

## 범위와 제한

- 기존 발표 기능을 임의로 제거하지 않고, 참조되지 않는 체험용 코드만 정리했습니다.
- GitHub 게시·업데이트 서버 검증, 다중 모니터 전체 시나리오, 모든 도구 조합은 이번 검증 범위에 포함하지 않았습니다.
- Vite의 500 kB 초과 청크 안내와 MSVC import library 생성 경고가 있으나 빌드는 성공했습니다.
- 코드 서명은 기존과 동일하게 없습니다.
- 기존 버전 설치 파일 및 사용자 PDF/필기 데이터는 삭제하지 않았습니다.
