## 원인과 수정

- 이전 선택/올가미가 빈 곳 드래그에서 같은 lasso 경로를 사용했습니다. 별도 box 모드를 추가했습니다.
- 회전 핸들은 이전 코드에 남아 있었으나 선택 작업 메뉴에 회전·반전 버튼이 빠져 있었습니다. 명시적 아이콘 버튼을 복구하고 반전 상태를 렌더·저장에 연결했습니다.
- 노트 100% 계산에 `min(너비 맞춤, 높이 맞춤, 1.1)`이 사용돼 900px 작업 영역에서 약 844px 대신 **431.48px**로 표시됐습니다. 너비를 기준 배율로 정의하고 페이지 맞춤을 분리했습니다.
- 두 하단 맞춤 동작이 모두 resetZoom을 호출했습니다. 이제 fitPage와 fitWidth를 별도로 호출하고 표시 모드도 동기화합니다.
- 무지에는 반복되는 질감 그라데이션이 있었고 스프링의 불투명 이미지가 배경색을 가렸습니다. 용지 스타일과 PDF 용지 그리기를 분리해 패턴·색을 명시하고 스프링 이미지를 사용하지 않습니다.
- 첫 사각 선택 UI 검사에서 pointer-move 경로에 box가 누락된 추가 결함을 발견했습니다. 실제 포인터 콜백을 구동하는 회귀 검사를 먼저 실패시키고 수정 후 통과 및 네이티브 재검증했습니다.

## 실행한 검증

- `node scripts/review3-notebook.cjs`: 수정 전 실제 컴포넌트 100% 너비 assertion 실패(431.48px). 수정 후 통과. 서로 다른 맞춤, 색·무지·스프링, 같은 spread 규격, 반전·회전 렌더, 텍스트 외곽선, 새 도형, 잔상 만료, 다중 노트 프로젝트 검사 포함.
- `node scripts/review3-selection.cjs`: 실제 AnnotationCanvas 포인터 down/move/up으로 사각 드래그 선택 검사. 수정 전 선택 []로 실패, 수정 후 ['ink']로 통과.
- `node scripts/v13-data.cjs`: PDF 페이지 편집·저장/재매핑, zoom 단계, undo/redo, 인쇄 범위 통과.
- `node scripts/toolbar-notebook-data.cjs`: 기존 화살촉 1:3·점선·필압/기울임·링크·프로젝트 호환 검사 통과.
- `npm run build`, `npm run lint`: 성공. Vite의 기존 500kB 청크 크기 안내만 남습니다.
- `npm run tauri:build -- --config src-tauri/tauri.review.conf.json`: Windows x64 실행 파일 및 NSIS 설치 파일 생성.
- 최종 네이티브 앱: 흰 무지, 페이지/너비 맞춤 차이, 숫자 입력·휠, 실제 사각 선택·회전·반전, 한글 서식, 노트 재로드, PDF 불러오기·저장 확인.
- `notebook-export.pdf`: 실제 앱에서 저장한 4페이지. 모든 페이지를 Poppler로 재렌더링해 시각 확인. 흰 배경·스프링 고리·회전/반전 필기·볼드/이탤릭/밑줄/외곽선 한글·가로 및 세로 PDF 페이지 모두 표시 정상.

## 저장·호환 및 범위

- 기존 Review1/2 노트는 첫 노트로 읽습니다. 활성 노트의 기존 필드(pages/annotations/view)를 유지하면서 books·activeBookId로 여러 노트를 보관합니다. `.crowshow`에 전체 라이브러리를 포함합니다.
- PDF 불러오기는 현재 노트 **뒤에 추가**하며 기존 페이지를 덮어쓰지 않습니다. 본문은 긴 변 약 1600/2262px 범위의 배경 이미지로 변환하며 원래 비율을 유지합니다. 동일 A4 규격 때문에 가로 PDF는 위아래 여백이 생깁니다.
- PDF의 본문 글자·벡터를 Notebook에서 개별 편집하는 기능은 아닙니다. PDF 내보내기는 노트·본문·필기를 이미지로 합쳐 저장하며 앱의 링크도 문구로 평면화됩니다.
- 로컬 저장소 용량 제한은 유지됩니다. 노트/PDF가 많을 때 저장 실패 안내가 나오면 프로젝트로 백업할 수 있습니다.
- 실제 펜 하드웨어와 작은 창의 모든 조합, 실제 설치·제거, Store 패키징은 이번 검증에 포함하지 않았습니다. Google Drive 연동은 비활성 상태입니다.
- 단위 검사에만 가짜 Canvas context/React hook 저장소를 사용했습니다. 실제 UI 확인은 새 로컬 네이티브 실행 파일로 수행했습니다.
