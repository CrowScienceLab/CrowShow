# CrowShow 1.2 — PDF 크기·화질·스크롤 개선

표시 버전 **1.2**, 내부 제품 버전 **1.2.0**, GitHub 태그 **v1.2.0**입니다.

- PDF의 72포인트를 화면의 96 CSS 픽셀로 환산하여 표준 100% 배율을 표시합니다. 기존의 100%는 화면 맞춤 배율이었습니다.
- `페이지 맞춤`, `너비 맞춤`, 실제 배율을 구분합니다. 배율 숫자를 누르면 100%, `0` 키는 페이지 전체 맞춤입니다.
- 확대된 문서는 가로·세로 스크롤바와 마우스 휠로 끝까지 읽을 수 있습니다. Shift+휠은 가로 이동, Ctrl+휠은 마우스 위치를 기준으로 확대합니다.
- Shift+드래그 또는 가운데 버튼 드래그로 확대된 화면을 이동합니다. 문서가 화면 안에 들어오면 휠로 이전·다음 페이지를 이동합니다.
- 화면 렌더링을 일반 배율에서 최소 2배 해상도로 처리하며 확대할 때 다시 렌더링합니다. 큰 확대에서는 캔버스 크기를 제한하고 PDF 이미지 캐시를 96MiB 이내로 관리합니다.
- PDF·필기·효과 레이어가 함께 스크롤됩니다. 작은 창에서도 배율 버튼이 잘리지 않도록 하단 바를 정리했습니다.
- 1.1의 업데이트 호환성, 대용량 PDF 구간 전달, 오프라인 한글/CJK 리소스 개선을 포함합니다.

## 설치

Windows x64 설치 파일 `CrowShow-v1.2-Setup-x64.exe`와 `SHA256SUMS.txt`를 제공합니다.
기존 앱의 업데이트 확인 또는 설치 파일 실행으로 업데이트합니다.
[버전별 기능](https://github.com/CrowScienceLab/CrowShow/blob/v1.2.0/VERSION_HISTORY.md)을 참고하십시오.

## 원본 품질의 범위

제공된 Entropy_Masterclass PDF는 13페이지이며 첫 페이지는 1376×768픽셀 이미지입니다.
페이지 크기는 1376×768포인트이므로 표준 100%에서 약 1835×1024 CSS 픽셀입니다.
표시 배율과 렌더링 품질은 개선했지만 이미지 원본에 없는 세부 정보는 생성하지 않습니다.
100%는 PDF 화면 배율이며, 모니터에서 자로 잰 실제 크기는 Windows 배율·모니터 설정에 따라 달라집니다.
