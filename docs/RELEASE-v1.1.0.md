# CrowShow 1.1 — Windows PC 정식 릴리스

PDF 업데이트 다운로드 오류, 대용량 문서의 초기 처리 부담, 일부 PDF의 한글 누락을 수정했습니다.
표시 버전은 **1.1**, Windows 제품 버전과 GitHub 태그는 **1.1.0 / v1.1.0**입니다.

## 변경 사항

- 이전 설치본이 요구하는 `SHA256SUMS.txt`를 정식 릴리스에 제공해 업데이트 다운로드를 복구했습니다.
- 새 앱은 버전명이 붙은 체크섬 파일도 읽으며, 업데이트 동의 후 발생한 다운로드·설치 오류를 안내합니다.
- 큰 PDF는 필요한 구간을 256KB 단위로 PDF.js 워커에 전달합니다.
- 모든 페이지 크기를 먼저 읽지 않고 첫 페이지부터 표시하며, 다른 페이지의 크기는 이동할 때 계산합니다.
- 썸네일은 화면에 보이는 항목과 주변 항목부터 만들고, 주변 페이지 사전 렌더링은 순차 처리합니다.
- PDF.js의 한글/CJK 문자 매핑, 표준 글꼴, 이미지 디코더, CMYK 색상 리소스를 설치본에 포함했습니다. 인터넷 연결 없이 사용합니다.
- 문서 교체 시 캐시를 정리하고 취소된 배경 렌더링이 캐시를 다시 채우지 않도록 했습니다.

## 제공 기능

PDF 열기·드래그 앤 드롭·최근 파일, 썸네일·전체화면·확대·이동, 펜·형광펜·텍스트·도형·지우개,
실행 취소·다시 실행, 레이저·스포트라이트·화면 가리기, 전환 효과·전환음, 발표자 화면·청중 창·메모·타이머,
자동 재생, `.crowshow` 프로젝트 저장, 필기 포함 PDF 내보내기를 제공합니다.

[버전별 상세 설명](https://github.com/CrowScienceLab/CrowShow/blob/v1.1.0/VERSION_HISTORY.md)

## 설치

- Windows x64: `CrowShow-v1.1-Setup-x64.exe`
- 검증 파일: `SHA256SUMS.txt`
- Tauri 2 / Windows WebView2 / 사용자별 NSIS 설치
- 1.0.0·1.0f의 앱 내 업데이트 또는 설치 파일 직접 실행으로 업데이트할 수 있습니다.
- 기존 PDF 기본 앱을 강제로 변경하지 않습니다.
- 코드 서명은 없습니다. [Windows 설치 보안 안내](https://github.com/CrowScienceLab/CrowShow/blob/v1.1.0/WINDOWS_SECURITY.md)를 확인하십시오.

## 검증 및 범위

제공된 약 132MB·103페이지 국문 가이드북에서 기존 한글 누락을 재현하고,
수정 후 표지·본문·지도·사진 설명·마지막 페이지 표시를 확인했습니다.
초기 워커 전달량은 256KB였으며 103개 중 화면 주변 썸네일만 생성했습니다.

원본 PDF는 최근 파일 저장·내보내기·청중 창 및 기존 필기 식별을 위해 메모리에 전체 보관합니다.
복잡한 이미지·벡터가 많은 페이지는 별도 렌더링 시간이 필요하며, 다중 모니터의 모든 조합을 검증한 것은 아닙니다.
